Capítulo 4 — Tornando Páginas Web Interativas com JavaScript

1. Introdução ao JavaScript

JavaScript é uma das três linguagens fundamentais da web, ao lado de HTML e CSS. Enquanto o HTML estrutura o conteúdo e o CSS cuida da aparência, o JavaScript é responsável por adicionar comportamento dinâmico e interatividade às páginas. O padrão da linguagem é chamado de ECMAScript, gerenciado pela Ecma International, e é publicado anualmente desde 2015. 


    console.log("Olá, mundo!");
    console.log("JavaScript deixa a página interativa.");

2. Como Incluir JavaScript em uma Página

Existem duas formas principais de incluir JavaScript em uma página HTML. A forma recomendada é criar um arquivo externo com a extensão .js e referenciá-lo no HTML usando o elemento <script src="caminho/arquivo.js"></script>. Isso mantém o código organizado e permite reutilizá-lo em diferentes páginas.

A segunda forma é escrever o código diretamente dentro de uma tag <script> no próprio HTML, mas essa abordagem não é recomendada porque mistura as responsabilidades do HTML e do JavaScript em um único arquivo.

Há ainda o elemento <noscript>, que exibe um conteúdo alternativo para o usuário caso o navegador não suporte JavaScript ou ele esteja desativado.

JS Interno


<script>
    console.log("Código diretamente no HTML");
</script>

JS Externo


<!DOCTYPE html>
<html>
<head>
    <title>JS Externo</title>
</head>
<body>

    <h1>Página</h1>

    <script src="script.js"></script>
</body>
</html>

3. Exibindo Caixas de Diálogo

JavaScript oferece três funções nativas para exibir caixas de diálogo no navegador. A função alert() exibe uma mensagem simples. A função confirm() exibe uma mensagem com opções de confirmar ou cancelar. A função prompt() abre uma caixa onde o usuário pode digitar um texto. Na prática, essas funções são pouco usadas porque têm aparência limitada e não podem ser estilizadas.

4. Console do Desenvolvedor

Todos os navegadores modernos oferecem um console de desenvolvedor que pode ser acessado pelas ferramentas de desenvolvimento. Ele é extremamente útil para testar e depurar código JavaScript. Por meio do objeto console, é possível enviar mensagens diretamente para esse console sem a necessidade de caixas de diálogo. Os métodos mais utilizados são:

console.log() mensagem normal; console.warn() aviso; console.error() erro; console.info() informação; console.debug() mensagem de depuração; console.clear() limpa o console.

5. Variáveis e Constantes

Variáveis são espaços na memória usados para armazenar valores que podem mudar durante a execução do programa. Em JavaScript, variáveis são declaradas com a palavra-chave let. Já as constantes, declaradas com const, recebem um valor uma única vez e não podem ser alteradas depois. Por convenção, constantes são escritas em letras maiúsculas, como const MAXIMO = 5000.

6. Tipos de Dados

JavaScript possui seis tipos de dados principais. Os três tipos primitivos mais comuns são: number (números inteiros e decimais, positivos ou negativos), string (sequências de texto delimitadas por aspas simples, duplas ou backticks) e boolean (valores lógicos true ou false). Além desses, existem os tipos especiais null e undefined, e o tipo object, que serve para representar estruturas de dados mais complexas.

Uma boa prática é usar const sempre que o valor de uma variável não precisar ser alterado. As template strings (criadas com backticks) permitem inserir valores de variáveis diretamente no texto usando a sintaxe ${variavel}. 

let numero = 1;
let texto = "Nome";
let ativo = true;

let vazio = null;
let indefinido;

let pessoa = {
    nome: "fulano",
    idade: 25
};

7. Operadores

Os operadores permitem trabalhar com os valores armazenados em variáveis e constantes. Os principais tipos são:

Aritméticos: realizam cálculos matemáticos — adição (+), subtração (-), multiplicação (*), divisão (/), módulo (%), potência (**), incremento (++) e decremento (--).

Atribuição: o operador = atribui um valor a uma variável.

Concatenação: o operador + também une duas strings em uma só.

Lógicos: && (E lógico), || (OU lógico) e ! (negação) trabalham com valores booleanos.

Comparação: ==, ===, !=, !==, <, >, <=, >= comparam valores e retornam um booleano.

8. Estruturas de Controle — Condicionais

As estruturas condicionais permitem que o programa tome decisões com base em condições. A instrução if executa um bloco de código se a condição for verdadeira. Com else, define-se o que acontece quando a condição é falsa. É possível encadear múltiplas condições com else if.

Para situações com muitos caminhos possíveis com base no valor de uma variável, usa-se o switch, que avalia o valor e executa o bloco correspondente ao case que combinar. O break encerra a execução do bloco atual, evitando que os blocos seguintes também sejam executados. O bloco default é executado quando nenhum case coincide. 


If Else:
let nota = 7;

if (nota >= 9) {
    console.log("Aprovado");
} else if (nota >= 6) {
    console.log("Aprovado");
} else {
    console.log("Reprovado");
}




switch:

let opcao = 3;

switch(opcao) {
    case 1:
        console.log("oção1");
        break;

    case 2:
        console.log("oção2");
        break;

    case 3:
        console.log("oção3");
        break;

    default:
        console.log("opção inválida");
}

9. Estruturas de Controle — Laços de Repetição

Os laços (loops) permitem executar um bloco de código repetidamente. Existem três tipos em JavaScript:

for: o laço de contagem clássico. Usa um contador inicializado, uma condição de parada e uma expressão de incremento. Ideal quando se sabe de antemão quantas vezes o código deve repetir.

while: o laço controlado pelo cabeçalho. Verifica a condição antes de cada iteração — se a condição já for falsa no início, o bloco nunca é executado.

do...while: o laço controlado pelo rodapé. Executa o bloco ao menos uma vez e só então verifica a condição. 


Exemplos:

For
for(let i = 1; i <= 5; i++) {
    console.log(i);
}

while

let contador = 1;
while(contador <= 5) {
    console.log(contador);
    contador++;
}


do while

let numero = 1;
do {
    console.log(numero);
    numero++;
} while(numero <= 5);

10. Funções

Funções são blocos de código reutilizáveis que podem ser chamados em diferentes partes do programa. Existem três formas de criá-las: a function declaration (usando a palavra-chave function seguida de um nome), a function expression (armazenando uma função anônima em uma variável) e as arrow functions (uma forma mais curta, usando =>).

Funções podem receber valores por meio de parâmetros e devolver resultados por meio da palavra-chave return. Isso torna as funções extremamente flexíveis e reutilizáveis, pois o mesmo código pode operar sobre dados diferentes a cada chamada. 


Exemplo de função com boas vindas:

function saudacao() {
    console.log("Olá fulano");
}

saudacao();

11. Tratamento de Erros

Durante a execução de um programa, diferentes tipos de erros podem ocorrer. Os erros de sintaxe surgem quando as regras gramaticais da linguagem são violadas (ex: esquecer um parêntese). Os erros de runtime ocorrem durante a execução, como tentar acessar uma variável que não existe. Os erros lógicos (bugs) acontecem quando o código roda sem falhas, mas produz um resultado incorreto por falha na lógica.

Para lidar com erros de runtime, usa-se o bloco try...catch: o código que pode gerar erro fica dentro de try, e caso um erro ocorra, o bloco catch é executado, recebendo o objeto de erro com informações sobre o problema. Erros também podem ser lançados manualmente com a instrução throw new Error("mensagem").

12. Objetos

Objetos permitem agrupar dados relacionados em uma única estrutura. Na notação literal, um objeto é criado com chaves {}, contendo pares de chave e valor chamados propriedades. Além de propriedades, objetos podem ter métodos, que são funções associadas ao objeto. Para acessar propriedades e métodos, usa-se a notação de ponto (objeto.propriedade). Dentro de um método, a palavra-chave this faz referência ao próprio objeto.

13. Arrays

Arrays são listas que armazenam múltiplos valores em sequência. São criados com colchetes [] e cada elemento é acessado por seu índice numérico, que começa em zero. Novos elementos podem ser adicionados com o método push() ou diretamente pelo índice. Arrays trabalham muito bem em conjunto com laços for, percorrendo cada elemento da lista.

Os principais métodos de arrays são: push() e pop() (adicionar/remover no final), shift() e unshift() (remover/adicionar no início), filter() (filtrar elementos), map() (transformar elementos), forEach() (iterar), sort() (ordenar), reverse() (inverter) e join() (converter em string). 


Declaração e manipulação de Array, Exemplo:

let numeros = [10, 20, 30];

console.log(numeros[0]); 
console.log(numeros[1]); 


numeros.push(40); 
numeros.unshift(5);


numeros.pop();
numeros.shift();
