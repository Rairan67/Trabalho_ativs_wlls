Capitulo 3

CSS: Formatando com Folhas de Estilo

Este capitulo aborda os fundamentos de CSS (Cascading Style Sheets), a linguagem usada para estilizar documentos HTML, separando conteudo (HTML) da apresentacao (CSS).



3.1 Introducao ao CSS


O que e CSS?

CSS significa Cascading Style Sheets. E uma linguagem de estilo para descrever a apresentacao de documentos HTML. Principais vantagens:

  • Maior controle sobre layout e aparencia
  • Reutilizacao de estilos em multiplas paginas
  • Facilidade de manutencao
  • Melhor acessibilidade

Estrutura de uma Regra CSS

seletor {
    propriedade: valor;
}

/* Exemplo */
p {
    color: blue;
    font-size: 16px;
}

Tres Formas de Incluir CSS

1. CSS Inline:

<p style="color: red;">Texto vermelho</p>

2. CSS Interno:

<head>
    <style>
        p { color: blue; }
    </style>
</head>

3. CSS Externo:

<link rel="stylesheet" href="estilos.css">

3.5 Cascata, Especificidade e Heranca


A Cascata

Ordem de prioridade quando multiplas regras se aplicam:

  1. Importancia - !important tem maior prioridade
  2. Especificidade - Seletores mais especificos vencem
  3. Ordem - Ultima regra declarada vence

Especificidade

Calculada como (A, B, C):

  • A = IDs (#id)
  • B = Classes, atributos, pseudo-classes (.classe, [attr], :hover)
  • C = Elementos, pseudo-elementos (div, ::before)
SeletorEspecificidade
*(0, 0, 0)
p(0, 0, 1)
.classe(0, 1, 0)
#id(1, 0, 0)
div.classe(0, 1, 1)
#id .classe p(1, 1, 1)
Inline style(1, 0, 0, 0)

Heranca

Propriedades herdadas: color, font-family, font-size, line-height, text-align, list-style

Propriedades NAO herdadas: margin, padding, border, background, width, height

3.9 Box Model


Todo elemento HTML e uma caixa composta por:

  • Content - Conteudo do elemento
  • Padding - Espaco interno entre conteudo e borda
  • Border - Borda ao redor do padding
  • Margin - Espaco externo ao redor da borda

box-sizing:

  • content-box - Width/height so inclui conteudo (padrao)
  • border-box - Width/height inclui padding e border

3.15 Media Queries


Permitem aplicar estilos baseados em caracteristicas do dispositivo:

/* Telas menores que 768px */
@media (max-width: 768px) {
    .container { flex-direction: column; }
}

/* Telas maiores que 1024px */
@media (min-width: 1024px) {
    .container { max-width: 1200px; }
}
