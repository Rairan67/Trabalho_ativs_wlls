Capitulo 3

CSS: Formatando com Estilo

Este capitulo aborda os fundamentos e conceitos avancados de CSS (Cascading Style Sheets), a linguagem usada para estilizar documentos HTML. CSS controla a apresentacao visual de paginas web, separando o conteudo (HTML) da aparencia (CSS).



3.1 Introducao ao CSS


3.1.1 O que e CSS?

CSS significa Cascading Style Sheets (Folhas de Estilo em Cascata). E uma linguagem de estilo usada para descrever a apresentacao de um documento escrito em HTML ou XML. CSS descreve como os elementos devem ser renderizados na tela, no papel, na fala ou em outras midias.

A principal vantagem do CSS e a separacao entre conteudo e apresentacao. Isso permite:

  • Maior controle sobre o layout e aparencia
  • Reutilizacao de estilos em multiplas paginas
  • Facilidade de manutencao
  • Melhor acessibilidade
  • Carregamento mais rapido das paginas

3.1.2 Estrutura de uma Regra CSS

Uma regra CSS consiste em um seletor e um bloco de declaracao:

Exemplo:

p{
color: blue;
font-size: 16px;
margin-bottom: 10px;
}

Neste exemplo:

  • p e o seletor (seleciona todos os paragrafos)
  • color, font-size e margin-bottom sao propriedades
  • blue, 16px e 10px sao valores

3.1.3 Tres Formas de Incluir CSS

Existem tres maneiras de aplicar CSS a um documento HTML:


1. CSS Inline (Estilo em Linha)

O estilo e aplicado diretamente no elemento HTML usando o atributo style:

<p style="color: red; font-size: 18px;">Este paragrafo e vermelho.</p>

Vantagens: Rapido para testar, especificidade alta.

Desvantagens: Dificil de manter, nao reutilizavel, mistura conteudo com apresentacao.


2. CSS Interno (Estilo Incorporado)

O estilo e definido dentro da tag <style> no <head> do documento:

<head>
    <style>
        p {
            color: blue;
            font-size: 16px;
        }
        h1 {
            color: green;
        }
    </style>
</head>

Vantagens: Estilos especificos para uma unica pagina, sem requisicoes HTTP adicionais.

Desvantagens: Nao reutilizavel entre paginas, aumenta o tamanho do HTML.


3. CSS Externo (Folha de Estilo Externa)

O estilo e definido em um arquivo .css separado e vinculado ao HTML:

<head>
    <link rel="stylesheet" href="estilos.css">
</head>

Conteudo do arquivo estilos.css:

p {
    color: blue;
    font-size: 16px;
}
h1 {
    color: green;
}

Vantagens: Reutilizavel, facil manutencao, cache do navegador, separacao completa.

Desvantagens: Requisicao HTTP adicional.



3.2 Seletores CSS

Seletores sao padroes usados para selecionar os elementos HTML que voce deseja estilizar. Existem varios tipos de seletores:


3.2.1 Seletores Basicos


Seletor Exemplo Descricao
Seletor de Tipo (Elemento) p Seleciona todos os elementos <p>
Seletor de Classe .minhaClasse Seleciona todos os elementos com class="minhaClasse"
Seletor de ID #meuId Seleciona o elemento com id="meuId"
Seletor Universal * Seleciona todos os elementos

Exemplos de uso:

/* Seletor de tipo */
h1 {
    font-size: 32px;
}

/* Seletor de classe */
.destaque {
    background-color: yellow;
}

/* Seletor de ID */
#cabecalho {
    background-color: #333;
    color: white;
}

/* Seletor universal */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

3.2.2 Seletores de Atributo

Seletores de atributo permitem selecionar elementos com base em seus atributos e valores:


Seletor Exemplo Descricao
[atributo] [title] Elementos que possuem o atributo title
[atributo=valor] [type="text"] Elementos com type exatamente igual a "text"
[atributo~=valor] [class~="btn"] Elementos cuja classe contem a palavra "btn"
[atributo|=valor] [lang|="pt"] Elementos com lang igual a "pt" ou comecando com "pt-"
[atributo^=valor] [href^="https"] Elementos cujo href comeca com "https"
[atributo$=valor] [href$=".pdf"] Elementos cujo href termina com ".pdf"
[atributo*=valor] [href*="google"] Elementos cujo href contem "google"

Exemplos praticos:

/* Links externos */
a[href^="http"] {
    color: blue;
}

/* Links para PDFs */
a[href$=".pdf"] {
    color: red;
}

/* Inputs de texto */
input[type="text"] {
    border: 1px solid #ccc;
    padding: 5px;
}

/* Elementos com atributo title */
[title] {
    cursor: help;
}

3.2.3 Seletores de Combinacao

Combinadores permitem selecionar elementos com base em sua relacao com outros elementos:


Combinador Exemplo Descricao
Descendente (espaco) div p Todos os <p> dentro de <div> (qualquer nivel)
Filho direto (>) div > p Todos os <p> que sao filhos diretos de <div>
Irmao adjacente (+) h1 + p O primeiro <p> imediatamente apos um <h1>
Irmaos gerais (~) h1 ~ p Todos os <p> que sao irmaos de <h1>

Exemplos:

/* Todos os links dentro de nav */
nav a {
    text-decoration: none;
}

/* Apenas filhos diretos li de ul */
ul > li {
    list-style: square;
}

/* Paragrafo imediatamente apos h2 */
h2 + p {
    font-weight: bold;
}

/* Todos os paragrafos irmaos de h2 */
h2 ~ p {
    margin-left: 20px;
}

3.2.4 Agrupamento de Seletores

Para aplicar os mesmos estilos a varios seletores, separe-os com virgulas:

h1, h2, h3 {
    font-family: Arial, sans-serif;
    color: #333;
}

.btn-primary, .btn-secondary, .btn-danger {
    padding: 10px 20px;
    border: none;
    cursor: pointer;
}


3.3 Pseudo-classes

Pseudo-classes sao usadas para definir um estado especial de um elemento. Elas permitem estilizar elementos com base em informacoes que nao estao contidas no documento.


3.3.1 Pseudo-classes de Link

Pseudo-classe Descricao
:link Links nao visitados
:visited Links ja visitados
:hover Elemento quando o mouse esta sobre ele
:active Elemento no momento do clique
:focus Elemento que tem foco (ex: input selecionado)

Ordem LVHA: E importante definir estas pseudo-classes na ordem correta: :link, :visited, :hover, :active.

a:link {
    color: blue;
}

a:visited {
    color: purple;
}

a:hover {
    color: red;
    text-decoration: underline;
}

a:active {
    color: orange;
}

input:focus {
    border-color: blue;
    outline: none;
    box-shadow: 0 0 5px rgba(0, 0, 255, 0.5);
}

3.3.2 Pseudo-classes Estruturais

Pseudo-classe Descricao
:first-child Primeiro filho de seu pai
:last-child Ultimo filho de seu pai
:nth-child(n) Enesimo filho de seu pai
:nth-last-child(n) Enesimo filho contando do final
:first-of-type Primeiro elemento daquele tipo
:last-of-type Ultimo elemento daquele tipo
:nth-of-type(n) Enesimo elemento daquele tipo
:only-child Elemento que e o unico filho
:only-of-type Unico elemento daquele tipo
:empty Elementos sem filhos

Formulas para nth-child:

  • :nth-child(odd) - elementos impares (1, 3, 5...)
  • :nth-child(even) - elementos pares (2, 4, 6...)
  • :nth-child(3n) - cada terceiro elemento (3, 6, 9...)
  • :nth-child(3n+1) - elementos 1, 4, 7, 10...
  • :nth-child(-n+3) - primeiros 3 elementos

/* Primeiro paragrafo */
p:first-child {
    font-weight: bold;
}

/* Ultimo item da lista */
li:last-child {
    border-bottom: none;
}

/* Linhas alternadas de tabela */
tr:nth-child(odd) {
    background-color: #f2f2f2;
}

tr:nth-child(even) {
    background-color: #ffffff;
}

/* Cada terceiro elemento */
li:nth-child(3n) {
    color: red;
}

/* Primeiros 3 itens */
li:nth-child(-n+3) {
    font-weight: bold;
}

3.3.3 Outras Pseudo-classes

Pseudo-classe Descricao
:not(seletor) Elementos que NAO correspondem ao seletor
:enabled Elementos de formulario habilitados
:disabled Elementos de formulario desabilitados
:checked Checkboxes e radios marcados
:required Campos obrigatorios
:optional Campos opcionais
:valid Campos com valor valido
:invalid Campos com valor invalido
:root Elemento raiz do documento (html)
:target Elemento alvo de um link ancora 

/* Todos os botoes exceto o desabilitado */
button:not(:disabled) {
    cursor: pointer;
}

/* Checkbox marcado */
input[type="checkbox"]:checked + label {
    text-decoration: line-through;
}

/* Campo invalido */
input:invalid {
    border-color: red;
}

/* Campo valido */
input:valid {
    border-color: green;
}

/* Elemento alvo de ancora */
:target {
    background-color: yellow;
}


3.4 Pseudo-elementos

Pseudo-elementos permitem estilizar partes especificas de um elemento. Usam a sintaxe com dois-pontos duplos (::).


Pseudo-elemento Descricao
::before Insere conteudo antes do conteudo do elemento
::after Insere conteudo apos o conteudo do elemento
::first-line Primeira linha de um bloco de texto
::first-letter Primeira letra de um bloco de texto
::selection Parte do texto selecionada pelo usuario
::placeholder Texto placeholder de inputs
::marker Marcador de itens de lista 

/* Capitular (primeira letra grande) */
p::first-letter {
    font-size: 3em;
    float: left;
    line-height: 1;
    margin-right: 10px;
}

/* Primeira linha em negrito */
p::first-line {
    font-weight: bold;
}

/* Adicionar aspas antes e depois de citacoes */
blockquote::before {
    content: open-quote;
    font-size: 2em;
}

blockquote::after {
    content: close-quote;
    font-size: 2em;
}

/* Icone antes de links externos */
a[href^="http"]::after {
    content: " ↗";
}

/* Estilo de texto selecionado */
::selection {
    background-color: yellow;
    color: black;
}

/* Placeholder de input */
input::placeholder {
    color: #999;
    font-style: italic;
}

/* Marcador de lista */
li::marker {
    color: red;
    font-weight: bold;
}


3.5 Cascata, Especificidade e Heranca


3.5.1 A Cascata

O "C" em CSS significa "Cascading" (Cascata). Quando multiplas regras podem ser aplicadas a um elemento, o navegador usa um algoritmo para determinar qual regra vence. A ordem de prioridade e:

  1. Importancia - Declaracoes com !important tem maior prioridade
  2. Origem - Estilos do autor > estilos do usuario > estilos do navegador
  3. Especificidade - Seletores mais especificos tem maior prioridade
  4. Ordem de aparicao - A ultima regra declarada vence (se especificidade for igual)

3.5.2 Especificidade

A especificidade e calculada com base nos tipos de seletores usados. Pode ser representada como uma tupla (A, B, C):

Componente Conta Exemplo
A Numero de seletores de ID #menu = 1
B Numero de classes, atributos e pseudo-classes .btn, [type], :hover = 1 cada
C Numero de elementos e pseudo-elementos div, ::before = 1 cada

Exemplos de calculo de especificidade:

Seletor Especificidade (A,B,C) Valor
* (0, 0, 0) 0
p (0, 0, 1) 1
p.texto (0, 1, 1) 11
p.texto.destaque (0, 2, 1) 21
#menu (1, 0, 0) 100
#menu .item (1, 1, 0) 110
#menu .item a (1, 1, 1) 111
#menu .item a:hover (1, 2, 1) 121
div#menu ul li.item a (1, 1, 4) 114
style="" (inline) (1, 0, 0, 0) 1000

Nota sobre !important: O uso de !important sobrepoe todas as outras regras, mas deve ser evitado pois dificulta a manutencao do codigo. Use apenas como ultimo recurso.

p {
    color: red !important; /* Sobrepoe todas as outras regras de color para p */
}

3.5.3 Heranca

Algumas propriedades CSS sao herdadas automaticamente dos elementos pais para os filhos. Isso e util para propriedades como fonte e cor do texto.


Propriedades que SAO herdadas (exemplos):

  • color
  • font-family, font-size, font-weight, font-style
  • line-height
  • text-align, text-indent, text-transform
  • letter-spacing, word-spacing
  • list-style
  • visibility
  • cursor

Propriedades que NAO sao herdadas (exemplos):

  • margin, padding
  • border
  • background
  • width, height
  • display
  • position

Valores especiais para controle de heranca:

Valor Descricao
inherit Forca a heranca do valor do pai
initial Usa o valor inicial da propriedade
unset Herda se a propriedade for herdavel, senao usa initial
revert Reverte para o estilo do user-agent (navegador) 

/* Forcar heranca de borda */
.container {
    border: 2px solid black;
}
.container * {
    border: inherit;
}

/* Resetar para valor inicial */
a {
    color: initial;
}

/* Usar all para resetar todas as propriedades */
.reset {
    all: unset;
}

Cores especificadas com valores de vermelho, verde e azul (0-255 ou 0%-100%):

color: rgb(0, 0, 255);        /* azul */
color: rgb(255, 255, 255);    /* branco */

/* Com porcentagens */
color: rgb(100%, 0%, 0%);     /* vermelho */

/* RGBA - com canal alfa (transparencia) */
color: rgba(255, 0, 0, 1);    /* vermelho opaco */
color: rgba(255, 0, 0, 0.5);  /* vermelho 50% transparente */
color: rgba(255, 0, 0, 0);    /* completamente transparente */

/* Sintaxe moderna (CSS4) */
color: rgb(255 0 0);          /* sem virgulas */
color: rgb(255 0 0 / 50%);    /* com alfa */

3.6.4 HSL e HSLA

Cores especificadas com matiz (hue), saturacao e luminosidade:

  • Hue (Matiz): 0-360 graus na roda de cores (0=vermelho, 120=verde, 240=azul)
  • Saturation (Saturacao): 0%-100% (0%=cinza, 100%=cor pura)
  • Lightness (Luminosidade): 0%-100% (0%=preto, 50%=cor normal, 100%=branco)
color: hsl(0, 100%, 50%);     /* vermelho */
color: hsl(120, 100%, 50%);   /* verde */
color: hsl(240, 100%, 50%);   /* azul */
color: hsl(0, 0%, 50%);       /* cinza */
color: hsl(0, 0%, 0%);        /* preto */
color: hsl(0, 0%, 100%);      /* branco */

/* HSLA - com canal alfa */
color: hsla(0, 100%, 50%, 0.5);  /* vermelho 50% transparente */

/* Sintaxe moderna */
color: hsl(0 100% 50%);          /* sem virgulas */
color: hsl(0 100% 50% / 50%);    /* com alfa */

3.6.5 Palavras-chave Especiais

color: transparent;     /* completamente transparente */
color: currentColor;    /* usa o valor atual de color */
color: inherit;         /* herda do elemento pai */

ex Altura do caractere "x" Raramente usado

/* Combinando unidades com calc() */
width: calc(100% - 20px);
height: calc(100vh - 60px);
font-size: calc(1rem + 1vw);

3.9 Box Model

O modelo de caixa (Box Model) e fundamental no CSS. Todo elemento HTML e tratado como uma caixa retangular composta por:

  1. Content: O conteudo do elemento (texto, imagem, etc.)
  2. Padding: Espaco entre o conteudo e a borda
  3. Border: A borda ao redor do padding
  4. Margin: Espaco externo, entre a borda e outros elementos

        +------------------------------------------+
        |               MARGIN                     |
        |   +----------------------------------+   |
        |   |           BORDER                 |   |
        |   |   +--------------------------+   |   |
        |   |   |        PADDING           |   |   |
        |   |   |   +------------------+   |   |   |
        |   |   |   |                  |   |   |   |
        |   |   |   |     CONTENT      |   |   |   |
        |   |   |   |                  |   |   |   |
        |   |   |   +------------------+   |   |   |
        |   |   +--------------------------+   |   |
        |   +----------------------------------+   |
        +------------------------------------------+

3.9.5 Box-sizing

Por padrao, width e height se aplicam apenas ao conteudo. box-sizing muda esse comportamento:

/* Padrao: width/height = apenas conteudo */
box-sizing: content-box;

/* width/height = conteudo + padding + border */
box-sizing: border-box;

/* Reset comum */
*, *::before, *::after {
    box-sizing: border-box;
}

3.9.6 Outline

/* Remover outline de foco (cuidado com acessibilidade) */

3.14 Flexbox

Flexbox e um modelo de layout unidimensional para organizar itens em linhas ou colunas.


3.14.1 Propriedades do Container (pai)

Propriedade Descricao Valores
display Ativa flexbox flex, inline-flex
flex-direction Direcao do eixo principal row, row-reverse, column, column-reverse
flex-wrap Quebra de linha nowrap, wrap, wrap-reverse
flex-flow Shorthand direction + wrap row wrap
justify-content Alinhamento no eixo principal flex-start, flex-end, center, space-between, space-around, space-evenly
align-items Alinhamento no eixo transversal stretch, flex-start, flex-end, center, baseline
align-content Alinhamento de multiplas linhas stretch, flex-start, flex-end, center, space-between, space-around
gap Espaco entre itens Valor ou row-gap column-gap

3.14.2 Propriedades dos Itens (filhos)

Propriedade Descricao Valores
order Ordem de exibicao Numero inteiro (padrao: 0)
flex-grow Fator de crescimento Numero (padrao: 0)
flex-shrink Fator de encolhimento Numero (padrao: 1)
flex-basis Tamanho base auto, valor com unidade
flex Shorthand grow shrink basis 0 1 auto (padrao)
align-self Alinhamento individual auto, stretch, flex-start, flex-end, center, baseline 

/* Container */
.container {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
}

/* Itens */
.item {
    flex: 1;              /* cresce igualmente */
}

.item-fixo {
    flex: 0 0 200px;      /* nao cresce, nao encolhe, 200px */
}

.item-especial {
    align-self: flex-end;
    order: -1;            /* aparece primeiro */
}

/* Centralizar vertical e horizontalmente */
.centralizado {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;
}

/* Navegacao responsiva */
.nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

/* Cards em grade responsiva */
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}
.card {
    flex: 1 1 300px;  /* cresce, encolhe, minimo 300px */
}

/* Footer fixo no fundo */
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}
main {
    flex: 1;
}


3.15 Grid

CSS Grid e um sistema de layout bidimensional que permite criar layouts complexos com linhas e colunas.


3.15.1 Propriedades do Container Grid

Propriedade Descricao Valores
display Ativa grid grid, inline-grid
grid-template-columns Define colunas Valores de tamanho
grid-template-rows Define linhas Valores de tamanho
grid-template-areas Define areas nomeadas Nomes de areas
gap Espaco entre celulas row-gap column-gap
justify-items Alinhamento horizontal dos itens start, end, center, stretch
align-items Alinhamento vertical dos itens start, end, center, stretch
justify-content Alinhamento do grid no container start, end, center, space-between, space-around, space-evenly
align-content Alinhamento vertical do grid start, end, center, space-between, space-around, space-evenly

3.15.2 Propriedades dos Itens Grid

Propriedade Descricao Valores
grid-column Posicao/span em colunas start / end ou span N
grid-row Posicao/span em linhas start / end ou span N
grid-area Nome da area ou posicao Nome ou row-start / col-start / row-end / col-end
justify-self Alinhamento horizontal individual start, end, center, stretch
align-self Alinhamento vertical individual start, end, center, stretch 

/* Grid basico */
.container {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
    gap: 20px;
}

/* Usando repeat() */
.grid-4-colunas {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 20px;
}

/* Grid responsivo com auto-fit */
.grid-responsivo {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

/* Grid com areas nomeadas */
.layout {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main aside"
        "footer footer footer";
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }

/* Item ocupando multiplas celulas */
.item-grande {
    grid-column: span 2;  /* ocupa 2 colunas */
    grid-row: span 2;     /* ocupa 2 linhas */
}

.item-posicionado {
    grid-column: 1 / 3;   /* da coluna 1 ate 3 */
    grid-row: 2 / 4;      /* da linha 2 ate 4 */
}

3.15.3 Funcoes Uteis do Grid

/* repeat() - repete valores */
grid-template-columns: repeat(3, 1fr);           /* 1fr 1fr 1fr */
grid-template-columns: repeat(3, 100px 50px);    /* 100px 50px 100px 50px 100px 50px */

/* minmax() - define minimo e maximo */
grid-template-columns: minmax(100px, 1fr);
grid-template-columns: repeat(3, minmax(200px, 1fr));

/* auto-fit e auto-fill */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));  /* ajusta quantidade */
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); /* preenche espaco */

/* fit-content() */
grid-template-columns: fit-content(300px) 1fr;

3.18 Media Queries

Media queries permitem aplicar estilos diferentes com base nas caracteristicas do dispositivo.


/* Sintaxe basica */
@media tipo and (condicao) {
    /* estilos */
}

/* Largura maxima (mobile first = min-width) */
@media (max-width: 768px) {
    .container {
        width: 100%;
    }
}

/* Largura minima */
@media (min-width: 768px) {
    .container {
        width: 750px;
    }
}

/* Combinando condicoes */
@media (min-width: 768px) and (max-width: 1024px) {
    /* estilos para tablets */
}

/* Breakpoints comuns */
/* Mobile: < 576px */
/* Tablet: 576px - 768px */
/* Desktop: 768px - 992px */
/* Large Desktop: > 992px */

@media (min-width: 576px) {
    /* Small devices */
}

@media (min-width: 768px) {
    /* Medium devices */
}

@media (min-width: 992px) {
    /* Large devices */
}

@media (min-width: 1200px) {
    /* Extra large devices */
}

/* Orientacao */
@media (orientation: portrait) { /* retrato */ }
@media (orientation: landscape) { /* paisagem */ }

/* Impressao */
@media print {
    .no-print {
        display: none;
    }
}

/* Preferencias do usuario */
@media (prefers-color-scheme: dark) {
    /* modo escuro */
}

@media (prefers-reduced-motion: reduce) {
    /* reduzir animacoes */
}
